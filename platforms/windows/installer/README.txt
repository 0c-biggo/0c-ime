靈犀注音（0c）

安裝完成後請登出再登入。「靈犀注音」已加入 Windows 語言設定
「中文（台灣）」的鍵盤，使用 Win＋空白切換；清單裡沒有時，在
「中文（台灣）」新增「靈犀注音」鍵盤。

升級：直接執行新版的 setup.exe，個人詞庫會保留，並另存一份到版本備份。
舊版（程式名為 zuin-*）也可直接升級，已加入的鍵盤不必重新加入。
解除安裝：Windows 設定 → 應用程式 → 已安裝的應用程式 → 靈犀注音。

個人詞庫位於 %LOCALAPPDATA%\Zuin\user.json。
解除安裝會停用輸入法，保留個人詞庫與版本備份（備份內含個人詞庫副本）；
完成後請登出再登入。

目前為內部預覽版，尚未公開發布；Word 等其他應用程式、乾淨機與
重新登入仍在驗收中。
